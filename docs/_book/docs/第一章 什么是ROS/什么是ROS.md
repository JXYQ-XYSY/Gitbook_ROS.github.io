# 1.ROS简介

### 1.1 什么是ROS

ROS（Robot Operating System，机器人操作系统）是一个由 **开源社区**驱动的、用于机器人系统开发的 **软件框架**。

> ⚠ 注意：ROS **不是**传统意义上的操作系统
> 它运行在 Linux 等操作系统上，提供机器人开发所需的**通信框架与工具链**



![img](https://www.ros.org/imgs/ros-equation.png)



#### 1️⃣ 通信基础（Plumbing）

在机器人系统中，**数据通信**往往是最先需要解决的问题。ROS 的核心是一套经过充分验证的 **消息通信系统**，也被称为 ROS 的“中间件”或“管道（Plumbing）”。
 ROS 基于 **发布 / 订阅（Publish / Subscribe）** 机制管理分布式节点之间的通信，开发者无需关注底层网络细节。

这种设计具备以下优势：

- 模块间**解耦**，提升系统稳定性（故障隔离）
- **接口清晰**、逻辑独立（关注点分离）
- 更易于**迭代维护、协同开发与功能复用**

同时，ROS 社区已形成大量**标准化消息格式**
可直接用于激光雷达、摄像头、定位算法、用户界面等多种场景，大幅提升软件兼容性与复用性。



#### 2️⃣ 高效开发工具（Tools）

机器人开发不仅涉及软件逻辑，还需与真实物理世界交互，因此调试难度大。
 为此，ROS 提供了一整套功能强大的开发工具：

ROS 自带专业工具链：

| 工具     | 用途                   |
| -------- | ---------------------- |
| RViz     | 数据与机器人状态可视化 |
| Gazebo   | 环境与传感器仿真       |
| rosbag   | 数据记录与回放         |
| rqt 系列 | 调试、图形监控、分析   |

这些工具能够显著加速机器人研发过程，同时也能直接随产品交付部署。



#### 3️⃣ 丰富的功能生态（Capabilities）

ROS 生态相当庞大，从硬件驱动到运动控制、从导航到机械臂操作，涵盖各种机器人领域：

| 功能类型 | 示例                       |
| -------- | -------------------------- |
| 硬件驱动 | 激光雷达、相机、IMU、GPS   |
| 算法模块 | SLAM建图、路径规划、控制器 |
| 高级系统 | MoveIt机械臂系统、导航栈   |
| 应用界面 | 人机交互工具、可视化展示   |

开发者可以直接基于这些现成模块构建机器人应用，而无需从零开始编写底层控制代码。

> 核心愿景：
>  **让更多有想法的人能够轻松构建机器人应用**



#### 4️⃣ 开源社区力量（Community）

ROS 社区是其最宝贵的资源之一：

- 来自全球的学生、科研人员、工程师共同参与
- 大量教程、开源代码、论坛讨论持续贡献
- 产业界（机器人公司、车厂）也深度采用

Open Robotics 作为中立维护机构，负责：

- 网站与社区服务托管
- ROS发行版管理与软件构建
- 核心系统功能持续开发和维护

社区的活跃与合作，使 ROS 能够不断进化、生态持续扩大。

>ROS = 强大的通信架构 + 高效的工具链 + 丰富的生态系统 + 全球社区协作
>让机器人开发更高效、更专业、更普及 



#### ✦ ROS 的核心目标

| 目标               | 说明                                   |
| :----------------- | -------------------------------------- |
| 降低机器人开发难度 | 统一接口、公共协议，让开发者专注于算法 |
| 提高软件复用性     | 功能组件化，可复用各类开源包           |
| 支持分布式系统     | 多台设备协同控制                       |
| 提供丰富工具和生态 | 可视化、仿真、导航、机械臂等           |

### 1.3 ROS1与ROS2的区别

随着机器人应用落地需求增多，ROS1 逐渐暴露一些不足，如实时性、通信可靠性等，因此 ROS2 诞生。

下表为两者主要差异：

| 对比项       | ROS1 (本课程使用)  | ROS2                          |
| ------------ | ------------------ | ----------------------------- |
| 通信中间件   | 自研 TCPROS/UDPROS | DDS工业级中间件（实时性更强） |
| 参数服务器   | 有中央参数服务器   | 分布式参数系统                |
| 多平台支持   | 主要 Linux         | Linux/Windows/MacOS           |
| 生命周期管理 | 不支持             | 支持节点生命周期管理          |
| 发布周期     | 已停止主线更新     | 持续迭代发展                  |

### 1.4 本课程选择版本及原因



#### ✦ 为什么课程采用 ROS1？

✔ 学习资料丰富，上手难度低
 ✔ 生态成熟，论文案例多
 ✔ 没有 DDS 复杂性，适合作为入门

> 课程采用 ROS1 Noetic + Ubuntu 20.04 （官方最后一个 ROS1 版本）



ROS1（Robot Operating System 1）是一个由 Open Source Robotics Foundation（OSRF）主导开发的开源机器人软件框架。
 它为机器人系统提供了：

- **统一的通信机制**
- **模块化的软件结构**
- **丰富的工具链**
- **庞大的功能包生态**



#### ROS1 的好处与优势

| 类别                         | ROS1优势                                |
| ---------------------------- | --------------------------------------- |
| 降低开发门槛                 | 不需要从零编写通信和硬件驱动            |
| **标准化通信协议**           | **各模块可无缝互联与复用**              |
| **大量开源功能包可直接使用** | **SLAM、Navigation、MoveIt 等现成算法** |
| 学习与社区资源丰富           | 教程、论坛、GitHub 大量可参考项目       |
| 强大的调试能力               | RViz、rqt、rosbag可视化与数据回放       |
| 支持分布式部署               | 多个节点运行在不同设备上仍能通信        |
| **行业认可度高**             | **成为服务机器人和科研行业事实标准**    |

> 学术界大量论文和实验平台都基于 ROS1
>  企业也有大量设备依赖其生态
