## 2.1 VMware17 Pro虚拟机安装教程



#### **为什么使用虚拟机**

相比**双系统或实体机**，虚拟机具备以下优势：

- 不影响原有 Windows 系统
- 环境统一，方便教学与排错
- 出问题可随时删除重装

#### 安装VMware

先找一个磁盘空间比较充裕的盘，然后首先创建一个文件夹 `VMware` 

建好 `VMware` 大的目录后，我们还需要在这个目录下创建 `安装目录-VMware`和之后`创建虚拟机的存放目录-VMwaredate`

![image-20251218174149832](assets/image-20251218174149832.png)



将我们上一节下载好VMware安装程序，以管理员身份运行：

![image-20251218195903657](assets/image-20251218195903657.png)



点完 `是` 以后这里需要稍微等待一会，才会显示安装界面：

![16d8a1fd94f2de19e892fc31466ef2b8](assets/16d8a1fd94f2de19e892fc31466ef2b8.jpg)

接收许可协议以后，点击 `下一步`：

![8becac22dda2780856627205fc926369](assets/8becac22dda2780856627205fc926369.jpg)

这里一定要点击 `更改...`，来更改安装位置，前文设置好的文件夹，选择我们刚刚创建的`VMware的安装目录`，然后点击`确定`：。

![b59d1823d7754e9926054bfddff36cc0](assets/b59d1823d7754e9926054bfddff36cc0.jpg)

如果出现这个弹窗直接点 `确定`，如果没有出现直接跳过这一步。

![acae59365b81232c02060ca3ae337804](assets/acae59365b81232c02060ca3ae337804.jpg)

将 `启动时检查产品更新` 和 `加入 VMware 客户体验提升计划`取消勾选，然后点击`下一步`：

![8241ded9777dd09c958d3ca64441f047](assets/8241ded9777dd09c958d3ca64441f047.jpg)

创建快捷方式，以方便寻找，并开始安装。

![364578d7d498d397c58224026aef46ca](assets/364578d7d498d397c58224026aef46ca.jpg)

![2a1f8e1739ccaaf6236850dc71591e72](assets/2a1f8e1739ccaaf6236850dc71591e72.jpg)

等待进度条跑完，安装完成：

![69df03dd2b6a5635a72168dbbe16e092](assets/69df03dd2b6a5635a72168dbbe16e092.jpg)

安装完成后会显示下面这个界面，直接点 `完成` 即可：

![4c219155f617a64eca1f60d9fbb1db26](assets/4c219155f617a64eca1f60d9fbb1db26.jpg)

这样就安装完成了（电脑不同深色主题可能会对这个有影响，无伤大雅）。
