## 2.2 安装Linux Ubuntu20.04

### 2.2.1 **下载Linux系统镜像地址**



清华镜像：[清华大学开源软件镜像站 | Tsinghua Open Source Mirror](https://mirrors.tuna.tsinghua.edu.cn/)

百度网盘：: https://pan.baidu.com/s/1Z0-rHOfq4ECthqtdDIzX8A?pwd=6711 提取码: 6711

首先进入该网站

![PixPin_2025-12-13_20-47-40](assets/PixPin_2025-12-13_20-47-40.jpg)

在搜索框中搜索`ubuntu`，并找到`ubuntu-releases`

![PixPin_2025-12-13_20-46-22](assets/PixPin_2025-12-13_20-46-22.jpg)

找到`20.04/`，点击开始下载

记得自己安装在哪个目录了！



### 2.2.2 创建虚拟机

首先我们需要选择虚拟机存放位置

![PixPin_2025-12-13_20-56-13](assets/PixPin_2025-12-13_20-56-13.jpg)

![PixPin_2025-12-13_20-56-44](assets/PixPin_2025-12-13_20-56-44.jpg)

### 虚拟机推荐配置（最低 / 推荐）

| 项目 | 最低配置 | 推荐配置 |
| ---- | -------- | -------- |
| CPU  | 2 核     | 4 核     |
| 内存 | 4 GB     | 8 GB     |
| 磁盘 | 50 GB    | 80 GB    |
| 网络 | NAT      | NAT      |
