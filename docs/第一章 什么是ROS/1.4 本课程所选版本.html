本课程所选版本

1.4 本课程选择版本及原因

✦ 为什么课程采用 ROS1？

✔ 学习资料丰富，上手难度低 ✔ 生态成熟，论文案例多 ✔ 没有 DDS 复杂性，适合作为入门

课程采用 ROS1 Noetic + Ubuntu 20.04 （官方最后一个 ROS1 版本）

ROS1（Robot Operating System 1）是一个由 Open Source Robotics Foundation（OSRF）主导开发的开源机器人软件框架。 它为机器人系统提供了：

  • 统一的通信机制
  • 模块化的软件结构
  • 丰富的工具链
  • 庞大的功能包生态

ROS1 的好处与优势

类别 ROS1优势
降低开发门槛 不需要从零编写通信和硬件驱动
标准化通信协议 各模块可无缝互联与复用
大量开源功能包可直接使用 SLAM、Navigation、MoveIt 等现成算法
学习与社区资源丰富 教程、论坛、GitHub 大量可参考项目
强大的调试能力 RViz、rqt、rosbag可视化与数据回放
支持分布式部署 多个节点运行在不同设备上仍能通信
行业认可度高 成为服务机器人和科研行业事实标准

学术界大量论文和实验平台都基于 ROS1 企业也有大量设备依赖其生态

ROS典型应用场景

应用方向 示例系统
移动机器人导航 扫地机器人、仓储搬运机器人
机械臂操作 工业机器人、协作机械臂
服务与交互机器人 餐厅服务、迎宾引导
自动驾驶系统 感知-定位-规划链路研制

ROS让研究者更关注算法与系统能力，而非底层通信。
