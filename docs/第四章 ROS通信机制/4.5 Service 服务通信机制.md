## 4.5 Service 服务通信机制

一句话定义：

> **Service 是 ROS 中用于“有请求、有响应”的同步通信机制。**

Service 的通信模型非常明确：

```
Client  —— 请求 ——>  Server
Client  <— 响应 ——   Server
```

Service 采用 **同步请求—响应模型**：

- 一次请求，对应一次响应
- 同步处理并返回结果（必须等返回）
- 调用期间客户端阻塞等待

**与topic对比**：

| 对比项   | Topic  | Service  |
| -------- | ------ | -------- |
| 通信模式 | 异步   | 同步     |
| 是否连续 | 是     | 否       |
| 典型用途 | 数据流 | 控制指令 |

> Topic     是“我说你听”，
>  Service 是“我问你答”。
